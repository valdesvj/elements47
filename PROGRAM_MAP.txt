LOCAL LABELS OF ELEM47
  Written by name in programs_rem (LBL :PANEL:, XEQ :PANEL:); the build gives each a free local number
  00-99 (the calculator files have numeric local labels only). listings/ELEM47_labels.txt lists name,
  number and job.

  :TABLE: :KEYS:          the table, then the key wait (PAUSE 50 / KEY? 33)
  :UP: :DOWN: :LEFT: :RIGHT: :MOVE:   8 2 4 6: direction, cursor off, :STEP:, cursor on, panel
  :INFO: :INFOKEY: :CLOSE:  5: the detail box, wait, close it (only the cells under it again)
  :QUIT:                  0: the end: PT deleted, CLREGS, CLSTK
  :TITLE:                 title and the key legend (two ATEXT with CR)
  :CELLS: :SEGMENT: :SEGLOOP: :SYMBOL: :SYMPCE:   every cell, by segments; symbols in order
  :CELL:                  one cell: box (unrolled AGRAPH), number, symbol
  :CLROW: :CLCOL: :CELLZ: closing the box: rows 3-7, columns 3-16, the Z from PT
  :CELLPOS: :FBLOCK:      the position of a cell (rows 8-9 lower)
  :CURSOR:                the cursor (XOR, unrolled)
  :PANEL:                 name, Z, mass (GRMOD 1 text, spaces after it)
  :RECORD: :RECSKIP: :RECGOT: :FIELD:   the record of Z (4 per data label), its fields in order
  :FIELDK: :FCUT:         field k of the text "a/b/c"
  :STEP: :STEPLP:         move the cursor, skip empty cells
  :DETAIL: :BOXCLR: :BOXLINE: :HDRBAR: :GRPNAM: :KELVIN: :STATES:   the detail box
  :GROUP: :GRP0: :GRPD: :GRPP: :GRPF: :GRPNAME:   the group name

  Data labels, numeric (XEQ IND):
  29      the segments of the table
  36-37   the symbols, 65 elements each (digit = column in the cell, then 2 characters)
  60-89   the records, 4 elements each: "name/mass/state letter/boiling point/configuration";
          60-74 in ELD1, 75-89 in ELD2 (:RECORD: puts the label in R43, XEQ "ELD1" or "ELD2",
          which does XEQ IND 43)

Folders:
  programs_rem/  the commented source: edit here (the DATA part is written by the build tool)
  programs/      the programs without comments, numeric labels (tools/build_elem47.py)
  build/         the file for the calculator (convert with rejig)
  listings/      numbered steps with the comments (step numbers = lines of programs/);
                 ELEM47_labels.txt: the named labels and their numbers
  python/        c47sim.py (the C47 simulator of Almanac 47), elements.py (the data),
                 elem47sim.py (runs ELEM47: pictures, step counts)
  tools/         build_elem47.py; build_free42.py (Free42); build_dev.py (programs_rem/dev -> build/dev)
  tests/         test_elem47.py, test_opt.py (screens against branch optimize), test_fw.py (the C47
                 firmware, T47), test_f42.py (Free42, f42run), test_dev.py (the dev programs);
                 calc/LTEST.txt (on the C47: the 196-character text)
  docs/          ELEM47_*.png (from the simulator)

Keys: 8 = 53, 2 = 73, 4 = 62, 6 = 64, 5 = 63, 0 = 82 (KEY? codes, as Almanac 47's menu).
